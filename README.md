# Species Identification Decision Tree

**Category:** Nature & Biology Tools

Three-tab app: (1) Interactive branching identification key for plants, insects, birds, and mammals using yes/no field-observable trait questions; (2) Species database manager to build your local flora/fauna catalog with traits, habitat, season, and status; (3) Sightings log with date, location, count, and confidence level. Species from your database appear in the identification tab for quick logging. All data persists in localStorage.
